Jungle Movie Lite - Chats-LLM Template Examples Build

What is new in this build:
- Saved Templates examples can now be generated by Chats-LLM.
- The app sends the template pattern, movie context, and original slot to the AI.
- The AI returns 3 complete, natural daily-life English examples.
- Each example includes a natural Arabic translation.
- Lara remains reserved for subtitle-line translation only.
- MyMemory remains available as a fallback for word/phrase translation and old examples.
- AI settings can be saved locally and synced to Supabase so they can be restored on another device.

Recommended Vercel environment variables:
CHATS_LLM_API_KEY=your_chats_llm_key
CHATS_LLM_MODEL=optional_model_id
CHATS_LLM_BASE_URL=https://chats-llm.com/api/v1

Lara environment variables still supported:
LARA_ACCESS_KEY_ID=your_lara_key_id
LARA_ACCESS_KEY_SECRET=your_lara_secret

How to use:
1. Upload the full project folder to Vercel, not index.html only.
2. Set CHATS_LLM_API_KEY in Vercel if you want the safer setup.
3. Or open Menu -> AI examples settings and paste the key once, then Save AI key to cloud.
4. Open Menu -> Saved templates.
5. Press Improve examples on one template or Improve all examples.
6. The new examples will be saved locally and synced to Supabase with the rest of your library.

Security note:
Saving API keys in Supabase is convenient for personal use across devices, but the safer method is Vercel environment variables.
