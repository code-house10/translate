المكتبة السحابية

احفظ الفيديو أو رابطه، ملف الترجمة، العبارات، الكلمات، والفلاش كارد لتفتحها من أي جهاز.

مهم: Vercel مناسب لاستضافة الصفحة فقط، لكنه لا يصلح لحفظ ملفات المستخدم داخل نفس ملف HTML. لهذا يستخدم هذا القسم Supabase Database + Storage لحفظ الفيديوهات والترجمات والعبارات والكلمات. أدخل بيانات مشروع Supabase مرة واحدة فقط، ثم استخدم نفس كود المكتبة على أي جهاز لجلب دروسك.
